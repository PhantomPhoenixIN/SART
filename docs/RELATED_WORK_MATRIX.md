## Initial novelty risk

The high-level idea of injecting graph/structure context into a recurrence router predates this project in bioMoR (August 2026 preprint), while AST/DFG-aware code transformers, adaptive computation, and looped code LMs also predate it. The defensible project contribution may be a carefully controlled empirical study in code translation, semantic-region rather than arbitrary-token routing, cross-language-normalized regions, and structural-difficulty mechanism tests. That is a provisional framing, not a novelty claim. The final paper must acknowledge bioMoR and any newer work discovered in the full search.

## Targeted update (2026-10-02)

Searches used: `"Mixture-of-Recursions adaptive depth transformers arXiv"`, `"LoopCoder recurrent computation code language models"`, `"StructCoder structure-aware transformer code generation"`, `"program structure conditioned adaptive computation recurrence code translation transformer"`, and `"code translation execution benchmark 2025"`. Primary sources opened: ACL Anthology's Findings ACL 2026 LoopCoder record; the arXiv records for MoR, StructCoder, TRACY and ACT. LoopCoder is a recent scaled code model based on dense-to-loop training; it establishes that looped code models are no longer a novel premise, but its described contribution is large-scale shared recurrence rather than SART's controlled semantic-region router. MoR is adaptive at token granularity and remains the relevant generic adaptive baseline; the current reproduction is explicitly labeled MoR-style in `docs/BASELINE_FIDELITY.md`. StructCoder uses AST/DFG in an encoder and target-side structural auxiliary tasks, reinforcing that structure use itself is not the claim. TRACY is a possible separate translated-program runtime-efficiency benchmark; it does not replace functional correctness or neural inference-cost profiling. No literature result justifies an unqualified “first” or broad novelty claim. Re-run a systematic search before manuscript submission, especially for 2026 work after this audit date.
